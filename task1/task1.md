## 1. Карта IT-ландшафта
task1_it_landscape_map.drawio

### Ключевые наблюдения из карты
- **АБС** — центральная система: её используют фронт-офис, бэк-офис депозитов, бэк-офис кредитов и кол-центр. Это «бутылочное горлышко» цифровизации.
- **Интернет-банк** интегрирован с АБС **напрямую через базу данных** (без API) — это главный архитектурный риск для масштабирования онлайн-каналов.
- **Ставки по депозитам** ведутся в **Excel** и передаются между подразделениями **по e-mail** — процесс не автоматизирован и зависит от ручного труда бэк-офиса.
- **СМС-оповещения** идут через СМС-шлюз → телеком-оператор, инициируются из АБС.
- **Партнёрский кол-центр** — внешняя система; с ней обмен только скриптами звонков (нет обмена данными о ставках).

## 2. Схема интеграции приложений
task1_integration_schema.drawio

### Вывод для дальнейших заданий
Главное препятствие к полностью цифровому продукту «депозит/накопительный счёт»:
1. Отсутствие единого хранилища актуальных ставок (только Excel + e-mail).
2. Прямая интеграция Интернет-банка с БД АБС без API и без изоляции нагрузки.
3. Обязательное участие бэк-офиса в каждом процессе открытия депозита (расчёт/согласование ставки вручную).

Эти три пункта становятся архитектурно значимыми требованиями для заданий 2–4.
