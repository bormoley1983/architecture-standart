# Architecture Standard Course

This repository contains the solution for the architecture assignment focused on digital transformation of a retail bank and online deposit products.

## Assignment scope

The project covers four deliverables aligned with the course task requirements:

- Task1: IT landscape map and application integration schema
- Task2: FURPS+ requirements table grouped by category
- Task3: ADR for online deposit opening process
- Task4: ADR for the new case, task list per system, and implementation roadmap

The repository is intended to be reviewed as a public Git repository with a pull request containing all required files.

## Review requirements

Important rule for submission:

- keep all required task folders visible in the pull request;
- do not hide the solution files with gitignore before review;
- ensure the repository is public so the reviewer can comment on the submission;
- do not make further changes after sending the review link until reviewer feedback is received.

## Project structure

The solution is organized by task:

- Task1 — IT landscape map and integration diagram
- Task2 — FURPS+ requirements matrix
- Task3 — ADR according to the prescribed template
- Task4 — ADR, system task breakdown, and roadmap
- tools/ — supporting architecture assets and PlantUML templates

## Solution references

Use the task folders as the main source of deliverables. Each task should contain the corresponding artifact set required by the assignment:

- Task1: current-state map and application integration schema
- Task2: requirements grouped by FURPS+ categories
- Task3: ADR describing the target solution
- Task4: ADR, implementation tasks by system, and roadmap

## Notes for review workflow

Do not add the task directories to `.gitignore` during the review phase. The reviewer must be able to inspect the final PR content and validate that all required files are present.

If you later want to clean up or archive the repository after review, that should happen only after the review is complete and after the assignment is accepted.
